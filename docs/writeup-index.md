## Publishing standards

- Add a separate Markdown write-up for each completed room or challenge.
- Record scope, tools, methodology, key observations, lessons learned, and defensive takeaways.
- Respect platform rules and do not publish prohibited flags, answer keys, credentials, tokens, or private data.
- Keep study reports clearly distinguished from hands-on CTF walkthroughs.
