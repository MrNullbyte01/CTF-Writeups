## Write-up template

- [CTF write-up template](docs/ctf-writeup-template.md)

Each new write-up should contain:

1. **Challenge / room** — platform and challenge name.
2. **Scope** — the authorised lab environment.
3. **Objective** — what the challenge asks the learner to achieve.
4. **Methodology** — high-level sequence of investigation steps.
5. **Findings** — relevant evidence and explanations.
6. **Lessons learned** — concepts reinforced and mistakes corrected.
7. **Mitigations** — defensive controls relevant to the weakness.
8. **References** — official documentation and learning resources.

## Responsible practice

All practical testing described here is limited to intentionally vulnerable labs, CTF platforms, or systems for which permission has been granted. Do not include real credentials, private keys, tokens, personal data, or flags where the platform rules prohibit publishing them.
